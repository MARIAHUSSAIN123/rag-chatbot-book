# Module 04: Machine Learning

**Weeks 15-21**

The full ML workflow plus core supervised and unsupervised algorithms.

## Week 15

### ML Pipeline

The end-to-end workflow from data collection to deployment.

### Feature Engineering

Create, transform and select features that improve models.

### Data Preprocessing

Handle missing values, encode categoricals and scale features.

## Week 16

### Train/Test Split & Cross Validation

Split data to evaluate models and avoid overfitting.

### Linear Regression

Predict continuous values using a linear relationship.

## Week 17

### Logistic Regression

Predict categories and model probabilities.

### Decision Trees

Tree-based models for classification and regression.

## Week 18

### Random Forest

An ensemble of trees for better accuracy and less overfitting.

### Gradient Boosting (XGBoost/LightGBM)

Advanced boosting for high-performance predictions.

## Week 19

### K-Nearest Neighbors (KNN)

Instance-based learning for classification and regression.

### Support Vector Machine (SVM)

Maximum-margin classifiers for complex data.

## Week 20

### K-Means Clustering

Partition data into clusters by similarity.

### Hierarchical Clustering

Build a hierarchy of clusters (agglomerative or divisive).

## Week 21

### Principal Component Analysis (PCA)

Reduce dimensions while keeping key information.
