# Module 02: Python for Data Science

**Weeks 7-10**

Work with NumPy, Pandas and visualization libraries to explore and present data.

## Week 7

### NumPy Core Operations

Arrays, vectorized operations and mathematical functions for fast numerical work.

### Pandas DataFrames

Create, index and manipulate tabular data.

## Week 8

### Data Cleaning & Transformation

Clean, normalize and prepare data for analysis.

### Handling Missing Values

Find and manage missing or null values.

## Week 9

### Merging, GroupBy

Combine datasets and aggregate them for analysis.

### Data Visualization (Matplotlib, Seaborn, Plotly)

Build charts, plots and interactive visuals.

## Practice
