# Module 01: Python Foundations

**Weeks 2-6**

Learn the core of Python: syntax, control flow, functions, data structures, files, errors and OOP.

## Week 2

### Variables, Data Types, Operators

Understand data types, declare variables, and use arithmetic, logical and comparison operators.

### Conditional Statements

Use if, elif and else to make decisions in programs.

## Week 3

### Loops & Iterations

Repeat tasks with for and while loops, plus break and continue.

### Functions, Lambda, Modules

Write reusable code blocks, anonymous (lambda) functions, and import Python modules.

## Week 4

### Python Data Structures

Organize data with lists, tuples, dictionaries and sets.

### File Handling

Read from and write to files for persistent storage.

## Week 5

### Exception Handling

Handle errors gracefully with try, except and finally.

### Object-Oriented Programming

Classes, objects, inheritance and encapsulation.

## Practice

Write your own short example for each topic above and run it before moving on.
