# Module 03: ML Ke Liye Statistics Aur Math

**Haftay 11-14**

Statistics, probability aur linear algebra jin par machine learning khari hai.

## Week 11

### Descriptive Statistics

Mean, median, mode, variance aur standard deviation se data ka khulasa.

### Probability & Distributions

Probability ki basics aur Normal, Binomial, Poisson distributions.

## Week 12

### Hypothesis Testing

Statistical tests se data ki bunyad par faisle karna.

### Covariance & Correlation

Variables ke darmiyan taalluq napna.

## Week 13

### Linear Algebra Basics

Vectors, matrices aur ML mein kaam aane wale operations.

### Cost Functions & Gradients

Loss functions aur gradient par mabni optimization.

## Mashq

Upar diye har topic ki apni chhoti misaal likhein aur agay barhne se pehle chala kar dekhein.
