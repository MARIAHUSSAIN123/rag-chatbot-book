# Module 04: Machine Learning

**Haftay 15-21**

Poora ML workflow aur bunyadi supervised aur unsupervised algorithms.

## Week 15

### ML Pipeline

Data jama karne se deployment tak poora workflow.

### Feature Engineering

Aise features banana, badalna aur chunna jo model behtar karein.

### Data Preprocessing

Missing values, categorical encoding aur feature scaling.

## Week 16

### Train/Test Split & Cross Validation

Model parakhne aur overfitting se bachne ke liye data ki taqseem.

### Linear Regression

Linear taalluq se continuous values ki peshgoi.

## Week 17

### Logistic Regression

Categories ki peshgoi aur probabilities ki modeling.

### Decision Trees

Classification aur regression ke liye tree-based models.

## Week 18

### Random Forest

Trees ka majmua jo accuracy barhata aur overfitting kam karta hai.

### Gradient Boosting (XGBoost/LightGBM)

Behtareen performance ke liye advanced boosting algorithms.

## Week 19

### K-Nearest Neighbors (KNN)

Instance-based learning, classification aur regression dono ke liye.

### Support Vector Machine (SVM)

Pechida data ke liye maximum-margin classifiers.

## Week 20

### K-Means Clustering

Mushabihat ki bunyad par data ko clusters mein baantna.

### Hierarchical Clustering

Clusters ka hierarchy banana (agglomerative ya divisive).

## Week 21

### Principal Component Analysis (PCA)

Ahem maloomat rakhte hue dimensions kam karna.

## Mashq

Upar diye har topic ki apni chhoti misaal likhein aur agay barhne se pehle chala kar dekhein.
